# Zerodha Website

A responsive and modern stock brokerage website inspired by the design and functionality of Zerodha. This project was built to practice front-end web development concepts, responsive layouts, and user interface design.

## 🚀 Features

* Responsive navigation bar
* Hero section with modern design
* Products page
* Pricing page
* About page
* Support page
* Stock information table
* Clean and user-friendly interface
* Mobile-friendly design

## 🛠️ Technologies Used

* HTML5
* CSS3
* JavaScript
* Font Awesome

## 🎯 Purpose

This project was developed to improve skills in:

* HTML and CSS
* Responsive Web Design
* JavaScript
* UI/UX Design
* Front-End Development
